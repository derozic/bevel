# Matter Protocol

Matter-compatible device interoperability for building and home/office automation.

## When to use

- Choosing Matter vs proprietary stacks
- Multi-vendor device fabrics
- Commissioning and controller topology

## Notes

- Prefer Matter for long-term multi-vendor
- Document fabric, controllers, bridges
- Thread border routers as infrastructure
- Security: commissioning codes handling = secrets (@veda)
