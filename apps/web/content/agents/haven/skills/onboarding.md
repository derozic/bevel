# Onboarding

Human and agent onboarding that produces time-to-first-value fast without security shortcuts.

## When to use

- New hire / contractor onboarding
- New fleet agent introduction
- Role changes needing access reset

## Tracks

| Day | Human | Agent |
|-----|-------|-------|
| 0 | Identity, laptop, accounts | Registry entry, SOUL/SKILL, runtime |
| 1 | Repo access, buddy, goals | Tools allowlist, channels |
| 7 | First meaningful PR/ship | First successful owned loop |
| 30 | Feedback + access review | Skill pack maturity review |

## Rules

- Access via least privilege (@veda / @argus)
- Culture and norms explicit (not tribal)
- Checklist versioned; improve after each cohort

## Output contract

```markdown
## Onboarding Plan — YYYY-MM-DD
**Who:** human | agent | both
**Role:** ...

### Checklist
| Item | Owner | Done-when |

### Success metric
time-to-first-value
```
