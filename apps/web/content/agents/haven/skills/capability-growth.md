# Capability Growth

Skill development paths for humans and agents — deliberate practice, not random courses.

## When to use

- Career / skill ladders
- Agent skill pack expansion plans
- Post-mortem training needs

## Growth loop

1. Assess current capability (evidence)
2. Target outcome (what they will deliver)
3. Practice reps with feedback
4. Ship proof in real work
5. Codify into docs/skills

## Output contract

```markdown
## Growth Plan — YYYY-MM-DD
**Person / agent:** ...
**Target capability:** ...

### Evidence of current level
...

### Practice plan
...

### Proof of level-up
...
```
