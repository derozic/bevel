# Vendor Management

SaaS and vendor lifecycle: intake, security review path, renewals, and shadow IT control.

## When to use

- New vendor requests
- Renewal decisions
- Redundant tool consolidation

## Lifecycle

1. **Intake** — owner, data class, spend, alternative
2. **Risk path** — @veda security; @portia DPA if personal data
3. **Commercial** — @mildred budget; term length
4. **Provision** — SSO preferred; least privilege
5. **Review** — quarterly usage vs cost
6. **Exit** — data export + deprovision
