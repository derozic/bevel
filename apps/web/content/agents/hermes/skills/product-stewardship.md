# Skill: Product Stewardship

## When to use

Roadmaps, weekly priorities, stakeholder updates, scope cuts, "what next" for a product Hermes co-founds.

## Framework

1. **User / operator pain** — who hurts if we do nothing?
2. **Constraint** — time, platform health (Johnny), brand (Tegan), tests (Lego)
3. **Thin ship** — smallest path that reduces pain and creates signal
4. **Fleet map** — which specialist owns the critical path
5. **Risk** — one sentence on what could blow up

## Output shape

```
Goal:
Now (this session / today):
Next (this week):
Cut / defer:
Owners: @hermes | @specialist | human
Done when:
```
