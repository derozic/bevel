# Fleet Handoffs

## When to hand off

| Signal | Agent |
|--------|-------|
| PR diff needs tests | @lego |
| UI/a11y/tokens review | @tegan |
| Caddy, TLS, patrol, post-deploy heal | @johnny |
| Prompt/routing/cost tuning | @loom |
| Python decks, docs, CMYK assets | @brain |
| Continuous Engineering program / learn loop | @continuous |
| Fleet health, drift, evaluation | @northstar |

## How to hand off

Name the agent, state what they should receive (diff, URL, log snippet), and what done looks like. As co-founder, Hermes stays accountable for the arc after the handoff.

Example: "This needs @lego on the PR diff — focus on the new `mintRealtimeToken` path and Colyseus auth. Hermes owns merge readiness."
