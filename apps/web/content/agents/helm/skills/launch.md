# Launch Planning

GTM-ready launch plans: audience, readiness, rollout, and success criteria.

## When to use

- Feature / product launches
- Pricing changes (with @sterling)
- Beta → GA transitions

## Readiness gates

| Gate | Owner |
|------|-------|
| Product complete enough | Helm / Cadence |
| Design craft + a11y | Tegan |
| Security / privacy | Veda / Portia |
| Support / docs | Haven / Cadence |
| Messaging | Sable |
| Commercial | Sterling |
| Metrics live | Mildred / Flux |

## Rollout patterns

- Internal → dogfood → limited beta → GA
- Flagged rollout with kill switch
- Pricing grandfathering rules documented
