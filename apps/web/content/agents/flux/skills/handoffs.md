# Handoffs

Clean ownership transfers between directors and ICs — no dropped balls.

## When to use

- Deal → legal → finance close
- Research → product → eng
- Incident commander rotations
- Agent-to-agent task transfer

## Handoff packet (minimum)

1. Context (what / why)
2. Current state
3. Decision needed or work remaining
4. Links / artifacts
5. Deadline / risk
6. Explicit next owner acceptance

## Anti-patterns

- "FYI" without owner
- Partial context in chat only
- Multiple owners (none accountable)

## Output contract

```markdown
## Handoff — YYYY-MM-DD
**From:** @x → **To:** @y
**Subject:** ...

### Context
...

### State
...

### Please do
...

### Accept criteria
...
```
