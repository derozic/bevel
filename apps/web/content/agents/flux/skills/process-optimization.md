# Process Optimization

Finding lag, rework, and waste in multi-team processes; proposing smaller better loops.

## When to use

- Slow cycle times across orgs
- Repeated escalations
- Tool sprawl / duplicate work

## Method

1. Map steps and wait states
2. Time each lag
3. Classify: value / necessary non-value / waste
4. Remove, combine, parallelize, or automate
5. Measure after change
