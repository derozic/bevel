# Frontier Scanning

Tracking arXiv, labs, launches, and pre-publication signals that could move Entity's roadmap.

## When to use

- Weekly frontier digest
- Sudden model / tooling shifts
- "What should Helm know this week?"

## Scan axes

| Axis | Signals |
|------|---------|
| Models | capability jumps, pricing, licenses |
| Tooling | agent frameworks, evals, infra |
| Safety / policy | regulations, papers, norms |
| Adjacent science | methods transferable to product |

## Digest format rules

- Max 7 items; ruthlessly prioritize
- Each item: what changed → so what for Entity → confidence
- Link primaries
- Tag urgency: watch | prototype | roadmap impact

## Output contract

```markdown
## Frontier Digest — YYYY-MM-DD

### Top signals
1. **Title** — so-what — urgency

### Ignore list (noise)
...

### Recommended next research
...
```
