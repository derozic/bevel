# Signal Detection

Spotting market, hiring, funding, product, and regulatory signals early.

## When to use

- Weekly intel digest
- Sudden competitor moves
- Category shifts for @helm / @spark

## Signal classes

| Class | Examples |
|-------|----------|
| Product | launches, pricing pages, docs diffs |
| GTM | job posts, ads, partner announcements |
| Capital | funding, M&A rumors (label as rumor) |
| Talent | key hires/departs |
| Policy | regulation affecting buyers |

## Output contract

```markdown
## Signal Digest — YYYY-MM-DD

### Material signals
1. **Signal** — so-what — confidence — owner to act

### Noise discarded
...
```
