# Pre-Sales Intelligence

Deep research packages that make sales conversations unfairly well-informed.

## When to use

- Before discovery / demo / negotiation
- RFP / technical validation prep
- Competitive displacement

## Package contents

1. Company snapshot & triggers
2. Likely pains mapped to product
3. Competitive landscape in account
4. Technical environment hypotheses
5. Landmine questions to ask
6. Proof assets to bring
