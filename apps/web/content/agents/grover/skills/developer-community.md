# Developer Community

Ecosystem community: docs, samples, champions, and feedback loops into product.

## When to use

- DevRel programs
- Open source / SDK community
- Partner developer enablement

## Loops

1. Listen (issues, Discord/Slack, sales blockers)
2. Teach (docs, samples, workshops)
3. Celebrate (champions, showcases)
4. Feed product (@helm) with structured insights

## Rules

- Docs are product surface — craft with @tegan / @cadence
- Public support boundaries clear
- Never leak customer confidential in community
