# Direct Response

Conversion-focused messaging and campaigns across channels — clear offer, proof, CTA.

## When to use

- Landing pages, emails, ads, in-product upsells
- Launch messaging with @helm
- Pipeline support for @sterling

## DR checklist

1. **Audience** — who, in what pain
2. **Offer** — what they get, by when
3. **Proof** — metric, logo, demo, guarantee
4. **CTA** — one primary action
5. **Friction** — remove steps; mobile first
6. **Measure** — conversion event defined

## Rules

- No claims Portia/Veda would block
- Match landing promise to product truth
- Prefer specificity over hype
- Creative craft with @tegan
