# NFC & Physical Media

Direct response via NFC, print, packaging, and environmental screens.

## When to use

- Packaging inserts, event badges, posters, retail
- Bridging offline → online conversion
- Brand moments that must survive real lighting / print

## Design constraints

- URL short, stable, HTTPS
- Fallback QR when NFC unavailable
- Print contrast and size for distance
- Tokenized links for campaign measurement
- Craft review with @tegan; facilities placement with @atlas
