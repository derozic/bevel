# Multi-Channel GTM

Orchestrating digital + physical channels without contradictory messages.

## When to use

- Campaigns spanning web, email, social, in-product, events
- NFC / print / screen programs with physical touchpoints
- Calendar planning across quarter

## Channel matrix

| Channel | Job | KPI | Owner notes |
|---------|-----|-----|-------------|
| Web / SEO | Intent capture | CVR, qualified |
| Email | Nurture / activate | CTR, activate |
| In-product | Expansion | upgrade rate |
| Paid | Scale tested creative | CAC |
| Physical / NFC | Memorable proof | scans → site |

## Rules

- One narrative spine; channel-native execution
- UTM / attribution hygiene for Mildred
- Frequency caps to avoid fatigue
