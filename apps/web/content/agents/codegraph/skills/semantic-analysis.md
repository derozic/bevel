# Semantic analysis

Cross-file resolution, call graphs, type hierarchies, and framework-aware route maps.

## Use when

- "Who calls this?"
- "What depends on this module?"
- "Where is this route defined?"
- "What is the minimal context for this change?"

## Discipline

- Answer with paths, symbols, and line anchors when available
- Separate facts (indexed) from inference (clearly labeled)
- Align with Karpathy engineering for developer roles: surgical context only, no bloat
