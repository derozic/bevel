# Deal Structuring

Term sheets, deal mechanics, negotiation frameworks, and margin-safe commercial packages.

## When to use

- Structuring enterprise / multi-year / custom deals
- Deal desk review before signature
- Expansion, co-term, or restructuring existing accounts
- Partner / marketplace revenue share design

## Deal anatomy

| Element | Questions Sterling answers |
|---------|----------------------------|
| Price | List, discount, ramp, true-up |
| Term | Length, renewal, auto-renew |
| Scope | Seats, usage, products, environments |
| Payment | Annual prepay vs quarterly; net-30/45 |
| Success | Pilot success criteria, go-live |
| Risk | Cap, liability path → @portia |
| Expansion | Uplift, land-and-expand triggers |

## Negotiation playbook

1. **Anchor on value outcomes** (time saved, revenue unlocked, risk reduced)
2. **Trade, never give** — every concession needs reciprocal (term, prepay, logo, case study)
3. **Protect floor** — if margin breaks, restructure scope before discounting further
4. **Paper early** — order form outline before verbal "we're done"
5. **Lost deals** — code reason + competitor within 48h

## Red flags (stop / escalate)

- Unlimited liability or uncapped indemnity without @portia
- Most-favored-nation pricing without expiry
- Free perpetual licenses
- Payment > net-60 without treasury approval (@mildred)
- Security / data terms that contradict @veda standards
